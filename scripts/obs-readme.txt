LPL SEASON 5 — графика эфира для OBS
=====================================

ЧТО ВНУТРИ
  LPL-S5-OBS-Scenes.json  — готовая коллекция из 10 сцен, все уже настроены
  LINKS.txt               — ссылки на каждую сцену (если добавлять руками)
  video/                  — 4 заставки видео-петлями (запасной вариант без интернета)

Сцены работают через интернет: расписание и счёт сами берутся из таблицы организатора.


БЫСТРЫЙ СТАРТ (2 минуты)
  1. OBS → меню «Коллекция сцен» → «Импорт».
  2. Выбрать файл LPL-S5-OBS-Scenes.json → «Импорт».
  3. Меню «Коллекция сцен» → выбрать «LPL S5 Broadcast».
  Готово: 10 сцен с графикой.

Если импорт не сработал — добавить руками (на каждую сцену):
  «+» в Источниках → «Браузер» → URL из LINKS.txt → Ширина 1920, Высота 1080 →
  галочка «Обновить браузер, когда сцена становится активной» → ОК.
  Эта галочка нужна, чтобы анимация появления проигрывалась при каждом переключении.


СЦЕНЫ
  Starting Soon     — отсчёт до ближайшего матча и команды. Всё из таблицы, трогать не надо.
  Be Right Back     — перерыв.
  Offline           — между игровыми днями.
  Thanks For Watching — конец эфира.
  Match Schedule    — матчи сегодняшнего дня (1–4 матча, вид подстраивается сам).
  Match Results     — итоги дня: счёт, победитель, техпоражения.
  Match MVP         — ник и K/D/A (меняются в ссылке, см. ниже).
  Casters           — две камеры кастеров + ники.
  Studio Camera     — одна камера.
  Studio Camera Draft — камера сверху, низ свободен под драфт.


КАМЕРЫ (Casters, Studio Camera)
  Окна в графике прозрачные. Камеру кладём ПОД графику:
  в списке Источников камера ниже, источник «HUD …» выше. Подогнать камеру по окну (Ctrl/Cmd+F — растянуть, потом уменьшить по рамке).


КАК МЕНЯТЬ НИКИ И СТАТИСТИКУ
  Проще всего — пульт: https://kerno-web.github.io/legends-league/hud/index.html
  Вписать ники / K D A → «Copy link» → в OBS двойной клик по источнику «HUD …» → вставить в URL → ОК.

  Или прямо в ссылке:
    MVP:      ...mvp.html?name=Bruuu_uuuh&k=12&d=3&a=9
    Кастеры:  ...casters.html?c1=Ник1&c2=Ник2
    Расписание / результаты за другой день:  ...schedule.html?day=21.11   ...results.html?day=20.11
    Отсчёт к своему времени (CET):  ...starting.html?to=18:30


ЕСЛИ ЧТО-ТО НЕ ТАК
  Не обновился счёт или расписание — данные обновляются из таблицы раз в 2 минуты;
    правый клик по источнику → «Обновить».
  Чёрный/пустой экран — нет интернета: включить видео из папки video/
    («+» → «Медиаисточник» → файл → галочка «Повтор»).
  Логотип команды не появился — название в таблице не совпало со списком команд; написать организатору.


---------------------------------------------------------------
ENGLISH (short)
  OBS → Scene Collection → Import → LPL-S5-OBS-Scenes.json → switch to "LPL S5 Broadcast".
  Manual: Browser source, URL from LINKS.txt, 1920×1080, tick "Refresh browser when scene becomes active".
  Camera windows are transparent: put the camera source under the HUD source.
  Names / MVP stats: operator page https://kerno-web.github.io/legends-league/hud/index.html → Copy link → paste as the source URL.
  No internet → use the MP4 loops in video/ (Media Source, Loop).
